This project presents a comprehensive, modular academic implementation of Polynomial Regression (Degree 3) applied to a Fitbit heart rate dataset. The core objective is to evaluate and compare the behavior, convergence stability, and performance of five distinct gradient-based optimization algorithms, explicitly incorporating and visualizing "Momentum" dynamics across all implementations.📂 Project Architecture & Notebooks StructureThe repository is modularly structured into five standalone Jupyter Notebooks, each strictly segmented into five pedagogical cells:Libraries Import: Essential data manipulation and visualization libraries (NumPy, Pandas, Matplotlib).Data & Feature Engineering: Fitbit dataset integration and Polynomial Feature construction (Degree 3) with robust feature standardization.Loss Function: Implementation of Mean Squared Error (MSE) to quantify model prediction error.Algorithm Logic with Momentum: Custom-built core optimization logic showcasing explicit velocity and momentum updates.Triple-Panel Visualization: Comprehensive evaluation plots showcasing:Actual vs. Predicted: Model fit against real data points.Loss Curve: Training loss convergence over epochs.Momentum Dynamics: Evolution of velocity/first-moment magnitude.⚙️ Implemented Optimization Algorithms & Momentum IntegrationGradient Descent (GD) with Momentum (1-polynomial-regression-gd.ipynb):Core Mechanism: Utilizes the entire dataset per epoch to compute gradients.Momentum Integration: Incorporates a velocity vector ($\nu_t = \beta \nu_{t-1} + \eta \nabla L$) to accelerate convergence along relevant directions and dampen oscillations.Stochastic Gradient Descent (SGD) with Momentum (2-polynomial-regression-sgd.ipynb):Core Mechanism: Updates parameters iteratively using individual randomly shuffled data samples.Momentum Integration: Stabilizes the inherently noisy trajectory of single-sample updates using historical velocity accumulation.Mini-Batch Gradient Descent with Momentum (3-polynomial-regression-minibatch.ipynb):Core Mechanism: Strikes an optimal balance by updating weights over small, randomized data batches.Momentum Integration: Combines the computational efficiency of batch processing with momentum smoothing to navigate local minima smoothly.RMSprop with Momentum (4-polynomial-regression-rmsprop.ipynb):Core Mechanism: Adapts the learning rate individually for each parameter based on a moving average of squared gradients.Momentum Integration: Blends adaptive scaling with a dedicated momentum velocity term for optimal non-convex surface navigation.Adam Optimizer (Explicit Momentum Analysis) (5-polynomial-regression-adam.ipynb):Core Mechanism: The state-of-the-art hybrid optimizer combining adaptive gradient estimates (RMSprop) with first-moment estimation.Momentum Integration: The first-moment vector ($m_t$) acts directly as the explicit momentum component, coupled with bias-correction mechanisms to achieve rapid and precise convergence (as visually validated by the optimal polynomial fit and stable MSE loss curve).📊 Key Evaluation MetricsLoss Function: Mean Squared Error (MSE).Loss Curve: Monitored across training epochs to ensure proper model convergence.Fit Quality: Visual alignment between actual Fitbit heart rate observations and the predicted cubic polynomial trajectory.
